# .NET Vertical Slice Architecture (VSA) Blueprint
This is my personal blueprint for building maintainable and scalable web applications with ASP.NET Core and .NET 10. 

I used my previous [.NET Clean Architecture Blueprint](https://github.com/jcdotnet/dotnet-clean-architecture) as the base and motivation for this project. By restructuring the app into self-contained features using **Vertical Slice Architecture (VSA)**, I wanted to compare both architectural styles and build a lean, high-performance template for my future projects.
